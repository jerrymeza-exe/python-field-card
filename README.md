# Python Field Card

A filterable Python cheat sheet for NeetCode and LeetCode problems: which tool to reach for, the built-ins and standard library calls you actually use, tested pattern templates (BFS, DFS, topological sort, union-find, Dijkstra, DP, tries, and more), an object-oriented design toolkit, and common Python gotchas.

**View it:** https://jerrymeza-exe.github.io/python-field-card/

Press `/` on the page to filter. Every code card is run against test cases on Python 3.9; features from newer versions are marked.

Companion page: [C++ Field Card](https://jerrymeza-exe.github.io/cpp-field-card/)
